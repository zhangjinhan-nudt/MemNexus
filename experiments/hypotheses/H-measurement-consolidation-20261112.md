## 1. 为什么撤回"修推导预算"

### 1.1 收益上限：3 题

`DETERMINISTIC DERIVATIONS` 段落 100% 被截断（LoCoMo 367/367、LME 24/24）。看起来是个大缺陷，但把"如果可见会怎样"算完，收益很小：

| 指标 | LoCoMo 1000 | LME 60 |
|---|---:|---:|
| 有推导的题 | 367 | 24 |
| 其中问时长/日期的题 | 22 | 9 |
| 账本里**能直接找到 gold 数值**的题 | **8（36%）** | **2（22%）** |
| 这 8 题当前已答对 | **5** | — |
| **可争取的上限** | **3 题** | ≤2 题 |

5/8 已经答对，说明模型即使没读到账本也能算对；剩下 3 题的账本内容虽含 gold，但是否真能让模型改对是未知的。**上限 3/1000 ≈ 0.3pt macro**。

而这个改动会：
- 让 367 题（37%）的提示文本变化；
- 若采用"挤占节点"方案，实测 **82/367 题会丢掉含 gold 词的节点**（cap=600）；
- 若采用"加法式"（抬高上限不挤占），新增字符中位 536、P90 1067、最大 1949，提示变长 8–25%。

**判据**：预期收益 ≤0.3pt，验证成本 ¥33，风险面 367 题。**收益/风险不成立，不做。**

### 1.2 但缺陷要记录，不能假装不存在

推导通道是死的这一事实必须写进设计文档与论文局限：**"我们计算了确定性推导，但在当前预算下它们不进入答案提示，因此机制收益由校验层承担，而非提示层。"** 否则后续任何人接手都会重复这个坑。

### 1.3 一个反直觉但重要的推论

既然 5/8 的题在账本不可见时仍答对，说明**模型自己能从原始证据算出时长**。这意味着：MemNexus 的时间能力主要来自「证据召回 + 校验层兜底」，不是「确定性推导」。论文里不能把时间题的表现归因于 ledger。

## 2. 当前证据强度盘点

| 结论 | 数字 | 强度 | 缺什么 |
|---|---|---|---|
| LoCoMo：MN 更好 | 配对 n=1000，MN 胜 316 / SM 胜 255 / 平 429，符号检验 **p=0.0107** | 中 | SM 仅 1 次 → **单边**，无法排除"那次跑偏" |
| LoCoMo：效应量 | 均值 F1 差 **+1.59pt**，Wilcoxon **p=0.097** | 弱 | 差值分布偏小，秩检验不显著 |
| LoCoMo：macro | MN 三次 56.43（SD 1.59） vs SM 53.90 | 中 | 同上，单边 |
| LME：打平 | MN 85.0（n=60，3 次） vs SM 83.0（n=53，1 次） | **弱** | n 小、SM 单次、跨轮 |
| LME：更便宜 | MN ¥0.122/题（含建库） vs SM ¥0.340/题 → **2.8×** | **强** | 成本是实测值，不是抽样 |

**关键判断**：成本优势是唯一"强"结论；两个准确率结论都缺 SM 侧的重复测量。所以钱应该花在 SM 的重复上，而不是花在新的代码改动上。

注意符号检验与 Wilcoxon 的分歧：MN 在**更多题上更好**（316 vs 255），但**单题改善幅度小**，所以秩检验只有 p=0.097。论文必须同时报这两个数，不能只挑显著的写。

## 3. 三个候选方向与逐项否决

### 3.1 LME 头对头扩到 n=400 —— **否决**

当前差距 2.5pt。配对标准误：

| n | SE | 差距 = 几个 σ |
|---:|---:|---:|
| 53（现状） | 6.8pt | 0.37σ |
| 400 | 2.5pt | **1.0σ** |
| 1000 | 1.6pt | 1.59σ |
| **3110** | 1.4pt | **1.96σ（80% power）** |

n=400 只有 1.0σ，做出来仍然是"测不出差别"。而它要花 ¥168（SM 占 ¥136）。

### 3.2 LME 单侧扩到 n=400 —— **采纳**

MN 单侧不需要和 SM 配对，成本只有建库 + 答题：

- 建库 400 × ¥0.104 / 2 = **¥21**
- 答题 3 次 × 400 × ¥0.018 / 2 = **¥11**
- 合计 **¥32**

收益：MN 的 LME 数字从「85.0% ±9pt（n=60）」变成「±2pt（n=400, 3 次）」。这是论文里能写的一个稳定数字，也是后续任何改动的进度仪。

### 3.3 实体约束检索（修 Miami 类失败）—— **否决**

想法：问题点名 Miami，检索却给了 Seattle，应过滤掉不含该实体的证据。

实测问题：用 `_query_entities` 检测"问题实体不在检索证据里"，LoCoMo 命中 **12.2%（122/996）**，但样例是 `Sunday`、`June`、`Four`、`Whose` —— 全是误报。**没有实体类型系统时，这个判据会把月份当人名**。要做就得先做 NER + 类型分类，工程量与本轮预算不匹配。

### 3.4 LME-S（论文主口径）—— **否决**

MN 建库 ¥2.27/题（半价 ¥1.14），SM 在 S 版单题 30 分钟以上且 24 题无一完成（历史实测）。100 题就要 ¥114 且只有单侧。论文里 LME 只能报 O 版 + 明确标注"非论文主口径"。

## 4. 推荐方案

### P1（¥102）：SM 在千题 LoCoMo 上补 2 次

**为什么是它**：这是唯一能把"MN 优于 SM"从单边变成双边的动作，而 LoCoMo 是 MN 领先的基准。MN 侧已有 3 次，不必再跑。

- 命令：`run_parallel_bench --cohort locomo_1000 --only-system SimpleMem --out sm_locomo_r2_20261113`，跑两轮
- 成本：SM ¥101.58/1000 题 → 半价 **¥51/次 × 2 = ¥102**
- 耗时：约 40 分钟/次

**预注册判据**：
- 主结论成立 ⇔ `MN 三次均值 − SM 两次均值 > 0` **且** 逐题符号检验 `p < 0.05`
- 若 `p ≥ 0.05` 或差值为负 → **降级为"打平"**，论文不得写"优于"，只能写"可比且成本更低"
- 必须同时报 Wilcoxon p（预期仍不显著），并说明"改善在频次而非幅度"

### P2（¥32）：LME-O 扩到 n≈400，MN 单侧 3 次

- 建队列：`build_lme_subset_cohort.py --setting O --per-category 67 --seed 20261112`（6 类 × 67 ≈ 402 题）
- 建快照：首轮带 `--snapshots result/lme_snapshots/o400`（缺失即建）
- 判据：
  - 三次均值 95%CI 半宽 **≤2.0pt**
  - temporal 分项不低于 n=60 时的 77.8% − 5pt（即 ≥72.8%）
  - 若 CI 半宽 >2.5pt（题量不足）→ **不加钱**，按实报告

### P3（¥66 缓冲）

留给两种意外：
- P1 的 SM 需要第 3 次（若两次差异 >3pt，说明 SM 方差大）→ ¥51
- 或 P2 需要补第 4 次 → ¥3.6

**合计 ¥134，留 ¥66。**

## 8. 这套安排的方法论依据

1. **测量优先于改动**：当前弱结论（准确率）比已知缺陷（推导截断）更卡论文，而弱结论的成因是"只有单边观测"，不是"系统不够好"。
2. **配对优于均值**：n=1000 的逐题配对给出 p=0.011，而 macro 均值对比只能给 1.9σ。同一个数据集，配对结构把功效提高了约 40%。所以预算应优先保证"配对两边都有重复"，而不是扩大样本。
3. **上限先算，再决定做不做**：推导预算这一项，如果先改再测，会花 ¥33 并改动 367 题提示，最后发现只值 3 题。先算上限是零成本的。
4. **成本优势是唯一已经"强"的结论**：它不依赖抽样，所以论文的落点应放在"同等质量、2.8× 更低成本 + 确定性层替代 N 次 LLM 调用"，而不是"我们更准"。后者在 ¥200 预算内无法确立。
