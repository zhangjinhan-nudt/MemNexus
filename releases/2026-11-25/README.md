```bash

python -m pytest tests -q
cd ../..
python -m pytest experiments -q
```

本机通过验收的是系统Python 3.13.3；后端最小 `.venv` 不含NumPy/Matplotlib，不能直接用来运行完整benchmark测试。请使用 `environment.json` 记录的实验环境。源码保留接受版本的字节内容，少量已有末尾空行/空格没有为格式清理而修改。
